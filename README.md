# ProofLayer – Software Testing Portfolio

A beginner QA portfolio project focused on manual testing, API testing, test documentation, and defect tracking.

## Project Overview

ProofLayer is a personal software testing practice project. It demonstrates practical QA activities performed on a sample website and REST API.

## Project Objectives

- Practise manual website testing.
- Create and execute functional test cases.
- Identify, document, and track defects.
- Perform REST API testing using Postman.
- Write automated API assertions.
- Maintain QA documentation and test evidence.

## Testing Activities

### 1. Manual Website Testing

- Functional testing
- Navigation testing
- Responsive testing
- Keyboard navigation
- Browser console checks
- Defect reporting and retesting

### 2. API Testing

API testing was performed using Postman with JSONPlaceholder.

HTTP methods covered:

- GET
- POST
- PUT
- PATCH
- DELETE

API test scenarios included positive and negative testing, response validation, status-code verification, and automated assertions.

## Disclaimer

ProofLayer is a personal learning and portfolio project. JSONPlaceholder is a simulated REST API used for practice. Its write operations do not permanently modify a production database.
